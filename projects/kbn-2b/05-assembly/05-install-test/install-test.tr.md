# 5.5 Kurulum kontrol listesi

Makineyi ilk kez çalıştırmadan önce aşağıdaki kontrolleri yapın ve işaretleyin.

Tablo: Kurulum kontrol listesi

| No | Kontrol | Referans | Sonuç |
|:---:|---|---|:---:|
| 1 | Kabin ve tank ünitesi terazide, tüm ayaklar zemine basıyor, kontra somunlar sıkılı | **Bkz. Bölüm 5.2.2** | ☐ |
| 2 | Makinenin çevresinde minimum boşluklar sağlanmış, tavan yüksekliği kapak açıkken makine yüksekliğinden büyük | **Bkz. Bölüm 3.5.2** | ☐ |
| 3 | Taşıma ve ambalaj sabitlemeleri sökülmüş, kabinde yabancı malzeme yok | **Bkz. Bölüm 5.1.2** | ☐ |
| 4 | Elektrik bağlantısı yapılmış, koruma iletkeni (PE) bağlı, panonun kapağı kapalı | **Bkz. Bölüm 5.3.1** | ☐ |
| 5 | Motorların dönüş yönü doğru | **Bkz. Bölüm 6.3.1** | ☐ |
| 6 | Tahliye manifoldundaki tüm vanalar kapalı, tahliye hattı bağlı | **Bkz. Bölüm 5.3.2** | ☐ |
| 7 | Buhar tahliye kanalı bağlı, kanal ağırlığı makineye binmiyor | **Bkz. Bölüm 5.3.4** | ☐ |
| 8 | Basınçlı hava bağlı, çalışma basıncı ayarlı | **Bkz. Bölüm 5.3.3** | ☐ |
| 9 | Süzgeç sepetleri ve filtre elemanları yerinde, filtre gövdesi kapakları sıkılı | **Bkz. Bölüm 10.1.3** ve **9.1.4** | ☐ |
| 10 | Kurutma fanının hava girişi açık, kurutma hava borusu bağlantıları sıkı | **Bkz. Bölüm 2.3.6** | ☐ |
| 11 | Tüm koruyucu paneller takılı | **Bkz. Bölüm 2.2.3** | ☐ |
| 12 | Uyarı etiketleri yerinde ve okunur | **Bkz. Bölüm 2.2.4** | ☐ |
| 13 | Güvenlik fonksiyon testleri tamamlanmış | **Bkz. Bölüm 5.4** | ☐ |

Tüm maddeler işaretlenmeden makineyi üretimde kullanmayın.
