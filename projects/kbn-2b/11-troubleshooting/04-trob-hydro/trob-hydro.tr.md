# 11.4 Yıkama devresi (pompa, filtre, nozul, döndürme) arızaları

Tablo: Yıkama devresi arızaları

| Belirti | Olası neden | Giderme yöntemi | Yapan |
|---|---|---|---|
| Yıkama veya durulama sırasında püskürtme zayıf ya da düzensiz | Süzgeç sepetleri tıkalı, sıvı tanka dönemiyor | Süzgeç sepetlerini temizleyin (**Bkz. Bölüm 10.1.3**). | Operatör |
| | Filtre elemanı tıkalı | Filtre elemanını değiştirin (**Bkz. Bölüm 9.1.4**). | Bakım personeli |
| | Tanktaki sıvı seviyesi düşük, pompa hava emiyor | Tankı doldurun (**Bkz. Bölüm 7.2.2**). | Operatör |
| | Nozullar tıkalı | Nozulları temizleyin (**Bkz. Bölüm 9.1.3**). | Bakım personeli |
| | Aşırı köpük nedeniyle pompa hava emiyor | Köpük nedenini giderin (**Bkz. Bölüm 7.6.3**). | Bakım personeli |
| | Pompa çarkı aşınmış | Pompayı kontrol ettirin; çarkı veya pompayı değiştirin. | Bakım personeli |
| | Pompa ters dönüyor | Faz sırasını kontrol ettirin (**Bkz. Bölüm 11.3**). | Elektrik personeli |
| Pompadan anormal ses geliyor | Filtre elemanı tıkalı veya pompa hava emiyor (kavitasyon) | Süzgeçleri ve filtreyi kontrol edin, sıvı seviyesini kontrol edin. | Bakım personeli |
| | Pompa veya motor rulmanı hasarlı | Rulmanları kontrol ettirin ve değiştirin. | Bakım personeli |
| Pompa milinden sıvı damlıyor | Mekanik salmastra aşınmış veya kuru çalışma nedeniyle hasar görmüş | Mekanik salmastrayı değiştirin (**Bkz. Bölüm 9.1.5**). | Bakım personeli |
| Filtre gövdesi kapağından sızıntı | Kapak contası hasarlı veya kapak eşit sıkılmamış | Kapağı **Bölüm 9.1.4**'e göre açın, contayı kontrol edin ve kapağı karşılıklı sıkın. | Bakım personeli |
| Sepet dönmüyor veya takılarak dönüyor, döndürme motoru alarmı | Yük dengesiz veya sepet kapasitesinin üzerinde | Yükü azaltın ve dengeli dağıtın (**Bkz. Bölüm 8.1**). | Operatör |
| | Sepet kabine sonuna kadar itilmemiş, dişli çember pinyona tam kavramıyor | Sepeti kabine sonuna kadar itin (**Bkz. Bölüm 7.4.2**). | Operatör |
| | Pinyon ile dişli çember arasına talaş sıkışmış | Talaşı temizleyin; dişleri kontrol edin (**Bkz. Bölüm 9.1.6**). | Bakım personeli |
| | Sepetin altına veya çevresine parça ya da talaş sıkışmış | Sıkışan parçayı çıkarın. | Bakım personeli |
| Tank tahliye vanası sızdırıyor | Vana tam kapanmamış veya contası aşınmış | Vanayı tam kapatın; sızıntı sürerse vanayı veya contasını değiştirin. | Bakım personeli |
