# 11.5 Pnömatik arızalar

**UYARI — Kapağın beklenmedik hareketi:** Pnömatik sisteme müdahale sırasında kapak aniden kapanabilir ve el, kol veya başın sıkışmasına yol açabilir. Pnömatik hortum, valf veya silindirlere müdahale etmeden önce kapağı tam kapalı konuma getirin veya açık kapağı mekanik olarak destekleyin; ardından basınçlı havayı kesip hattaki basıncı boşaltın (**Bkz. Bölüm 2.3.3**).

Tablo: Pnömatik arızalar

| Belirti | Olası neden | Giderme yöntemi | Yapan |
|---|---|---|---|
| Kapak açılmıyor veya kapanmıyor | Tesis hava hortumu hava girişine takılı değil veya tesis hava vanası kapalı | Hortumu hava girişindeki rakora takın; tesis vanasını açın. | Operatör |
| | Kapı açıklığında ışık perdesini kesen bir engel var | Engeli kaldırın (**Bkz. Bölüm 11.6**). | Operatör |
| | Hava basıncı düşük | Regülatördeki basıncı kontrol edin ve **Bölüm 6.5**'teki değere ayarlayın; tesis hattının basıncını kontrol ettirin. | Bakım personeli |
| | Valf bobinine enerji gelmiyor | Bobin beslemesini, PLC çıkışını ve kumanda devresini kontrol edin. | Elektrik personeli |
| | Valf bobini veya valf arızalı | Valfi elle kumanda ederek kontrol edin; arızalı bobini veya valfi değiştirin. | Bakım personeli |
| Kapak çok yavaş veya sarsıntılı hareket ediyor | Hava basıncı düşük | Basıncı ayarlayın (**Bkz. Bölüm 6.5**). | Bakım personeli |
| | Silindir hız ayar (kısma) valfleri yanlış ayarlı | Hızı **Bölüm 6.5**'e göre ayarlayın. | Bakım personeli |
| | Şartlandırıcı filtresi tıkalı | Filtre elemanını temizleyin veya değiştirin (**Bkz. Bölüm 9.1.8**). | Bakım personeli |

| Sürekli hava kaçağı sesi geliyor | Hortum veya rakor gevşek ya da hasarlı | Kaçak noktasını bulun; rakoru sıkın veya hortumu değiştirin. | Bakım personeli |

| Silindir milinde su veya pas izi | Basınçlı havada nem var | Şartlandırıcıdaki yoğuşma suyunu boşaltın; tesis hava kurutucusunu kontrol ettirin. | Bakım personeli |
