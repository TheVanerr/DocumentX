# 11.2 Genel arızalar ve yıkama kalitesi sorunları

Tablo: Genel arızalar

| Belirti | Olası neden | Giderme yöntemi | Yapan |
|---|---|---|---|
| Makine çalışmıyor, HMI ekranı kapalı | Ana şalter kapalı | **Ana şalteri** "I" konumuna getirin. | Operatör |
| | Tesis tarafındaki besleme sigortası kapalı veya atmış | Besleme sigortasını kontrol ettirin. | Elektrik personeli |
| | Kumanda devresi sigortası veya HMI beslemesi arızalı | Sigortaları ve HMI beslemesini kontrol edin. | Elektrik personeli |
| Program başlamıyor | Acil durdurma butonu basılı veya acil durdurma alarmı onaylanmamış | Butonu serbest bırakın ve alarmı onaylayın (**Bkz. Bölüm 2.3.2**). | Operatör |
| | Kapak tam kapanmamış | Kapağı tam kapatın; kapak kılavuzlarında ve kapağın alt kenarında parça veya talaş olmadığını kontrol edin. | Operatör |
| | Kapak emniyet şalteri kapağı algılamıyor | Şalteri ve konumunu kontrol edin (**Bkz. Bölüm 11.6**). | Bakım personeli |
| | HMI'da aktif alarm var | Alarmın nedenini giderin ve alarmı onaylayın (**Bkz. Bölüm 3.4.3**). | Operatör / bakım personeli |
| | Program seçilmemiş veya program süreleri sıfır | Programı seçin ve parametrelerini kontrol edin (**Bkz. Bölüm 6.6**). | Operatör |
| Parçalar temiz çıkmıyor | Yıkama tankı sıcaklığı düşük | Sıcaklığın ayar değerine ulaşmasını bekleyin; program ayarını kontrol edin (**Bkz. Bölüm 6.6**). | Operatör |
| | Yıkama süresi kısa | Program ayarında yıkama süresini artırın (**Bkz. Bölüm 6.6**). | Bakım personeli |
| | Kimyasal konsantrasyonu düşük veya yıkama sıvısı aşırı kirlenmiş | Kimyasal ekleyin veya sıvıyı değiştirin (**Bkz. Bölüm 10.1.4**). | Operatör / bakım personeli |
| | Nozullar veya filtre elemanları tıkalı | Nozulları temizleyin, filtre elemanlarını değiştirin (**Bkz. Bölüm 9.1.3** ve **9.1.4**). | Bakım personeli |
| | Parçalar birbirini örtüyor veya püskürtme yönüne kapalı yerleştirilmiş | Parçaları **Bölüm 8.2**'ye göre yeniden yerleştirin. | Operatör |
| | Sepet dönmüyor | **Bölüm 11.4**'teki ilgili satıra bakın. | Bakım personeli |
| Parçalarda leke veya kimyasal kalıntısı kalıyor | Durulama sıvısı kirlenmiş | Durulama sıvısını değiştirin (**Bkz. Bölüm 10.1.4**). | Bakım personeli |
| | Durulama süresi kısa | Program ayarında durulama süresini artırın (**Bkz. Bölüm 6.6**). | Bakım personeli |
| | Kimyasal konsantrasyonu yüksek | Yıkama sıvısını tedarikçinin önerdiği konsantrasyona göre seyreltin. | Bakım personeli |
| Parçalar kurumuyor | Kurutma süresi veya sıcaklığı düşük | Program ayarında kurutma süresini veya sıcaklığını artırın (**Bkz. Bölüm 6.6**). | Bakım personeli |
| | Parçalarda su biriken cepler yukarı bakıyor | Parçaları **Bölüm 8.2**'ye göre yeniden yerleştirin. | Operatör |
| | Kurutma fanı veya hava ısıtıcısı çalışmıyor | **Bölüm 11.3**'teki ilgili satıra bakın. | Elektrik personeli |
| | Durulama sıvısı soğuk, parçalar soğuk kalıyor | Durulama tankı sıcaklığını kontrol edin (**Bkz. Bölüm 6.6**). | Operatör |
| Aşırı köpük oluşuyor | Kimyasal yüksek köpüren tipte veya fazla eklenmiş | Düşük köpüklü kimyasal kullanın; konsantrasyonu düşürün (**Bkz. Bölüm 7.6.3**). | Bakım personeli |
| | Durulama sıvısı yıkama sıvısıyla kirlenmiş | Durulama sıvısını değiştirin. | Bakım personeli |
| Program sırasında kapak kenarlarından sıvı, buhar veya sıcak hava çıkıyor | Kapak tam kapanmamış | Kapağı tam kapatın; kılavuzları temizleyin (**Bkz. Bölüm 10.1.3**). | Operatör |
| | Kapak eğilmiş veya kılavuzlarında aşınma var | Kapağı ve kılavuzları kontrol ettirin (**Bkz. Bölüm 9.1.7**). | Bakım personeli |
| Kabin çevresine buhar yayılıyor | Buhar tahliye fanı çalışmıyor | **Bölüm 11.3**'teki ilgili satıra bakın. | Elektrik personeli |
| | Buhar tahliye kanalı tıkalı veya bağlantısı ayrılmış | Kanalı ve bağlantısını kontrol edin (**Bkz. Bölüm 9.1.9**). | Bakım personeli |
| Makine çevresinde zeminde sıvı birikiyor | Pompa, filtre gövdesi, boru veya tahliye manifoldunda sızıntı | Sızıntı noktasını bulun; bağlantıyı sıkın veya contayı değiştirin. | Bakım personeli |
| | Tanklardan biri fazla doldurulmuş, sıvı taşıyor | Tankı seviye sınırına kadar boşaltın (**Bkz. Bölüm 7.2.2**). | Operatör |
| Sepet arabaya çekilemiyor veya kabine itilemiyor | Taşıma arabası rayları kabin raylarıyla hizalı değil | Arabayı yeniden hizalayın (**Bkz. Bölüm 7.4.2**). | Operatör |
| | Raylarda talaş veya sıkışmış parça var | Rayları temizleyin (**Bkz. Bölüm 9.1.10**). | Operatör |
| | Sepet makaraları dönmüyor veya hasarlı | Makaraları kontrol ettirin ve değiştirin. | Bakım personeli |
