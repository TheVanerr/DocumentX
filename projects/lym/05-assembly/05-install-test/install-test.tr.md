# 5.5 Kurulum kontrolü ve deneme çalıştırması

Bu alt bölüm, kurulumun tamamlandığını doğrulayan kontrol listesini ve makinenin üretime alınmadan önceki deneme çalıştırmasını tanımlar. Kontrol listesinin tüm maddeleri "Evet" olarak işaretlenmeden makine üretim amacıyla kullanılmamalıdır.

## 5.5.1 Mekanik kurulum kontrolü

| No | Kontrol | Evet / Hayır |
| :---: | :--- | :---: |
| 1 | Makine **Bölüm 5.2**'ye göre hizalandı; sapma 10 mm'nin altında. | |
| 2 | Dört ayak da zemine tam olarak basıyor. | |
| 3 | Taşıma arabasının montajı yapıldı (taşıma arabası bulunan makinelerde). | |
| 4 | Taşıma arabası ile makine birbirine tam oturuyor; sepet takılmadan sürülebiliyor. | |
| 5 | Kapak gövdeye düzgün oturuyor; amortisörler kapağı açık konumda taşıyor. | |
| 6 | Ön filtre ve emiş filtresi yerinde (**Bkz. Bölüm 10**). | |
| 7 | Tahliye vanası kapalı; su ve tahliye bağlantılarında sızıntı yok. | |

## 5.5.2 Elektrik devreye alma kontrolü

Elektrik kontrolleri yetkili elektrik personeli tarafından, aşağıdaki sırayla yapılır. Enerji verme sırası: ana şalter, kaçak akım koruma cihazı, devre kesiciler.

| No | Kontrol | Evet / Hayır |
| :---: | :--- | :---: |
| 1 | Şebeke bağlantısı tamamlandı; koruma topraklaması (PE) sürekliliği doğrulandı. | |
| 2 | Ana şalter **1** konumuna getirildi. | |
| 3 | Pano içindeki kaçak akım koruma cihazı ve tüm devre kesiciler açık (devrede) konumda. | |
| 4 | Faz sıra rölesi çıkış veriyor (röle üzerindeki durum göstergesi ile kontrol edilir). | |
| 5 | Acil stop serbest konumda; RESET butonuna basıldığında reset lambası yanıyor. | |

Faz sıra rölesi çıkış vermiyorsa, ana şalteri **0** konumuna getirin, tesis tarafında besleme devresini kilitleyin ve yetkili elektrik personeline prizdeki iki faz iletkeninin yerini değiştirtin. Faz değişikliğini makine panosu içinde yapmayın.

## 5.5.3 Deneme çalıştırması

Güvenlik fonksiyonlarının testi (**Bkz. Bölüm 5.4**) başarıyla tamamlandıktan sonra deneme çalıştırmasını yapın:

1. Tankın dolu olduğunu kontrol edin (**Bkz. Bölüm 5.3.2**).
2. Isıtıcı şalterini **1** konumuna getirin ve termostatta hedef sıcaklığı ayarlayın (**Bkz. Bölüm 3.4.8**). Termostat ekranındaki ölçülen sıcaklığın (PV) yükseldiğini gözlemleyin.
3. Sepet boşken TEST butonuna basın; sepetin takılmadan ve anormal ses çıkarmadan döndüğünü kontrol edin.
4. Kapağı kapatın, zamanlayıcıyı ayarlayın ve START butonuna basın.
5. Makineyi boş sepetle **60 dakika** çalıştırın. Bu süre zamanlayıcıda tek çevrim veya birden fazla çevrim olarak ayarlanabilir.
6. Çalıştırma süresince pompada ve redüktörde anormal ses veya titreşim olmadığını kontrol edin.
7. Boru bağlantılarında, pompa salmastrasında ve tahliye vanasında sızıntı olmadığını kontrol edin.
8. Arıza lambalarından hiçbirinin yanmadığını ve makinenin zemin üzerinde kaymadığını kontrol edin.
9. Süre sonunda pompanın ve sepetin otomatik olarak durduğunu kontrol edin.

Deneme çalıştırması sırasında bir arıza lambası yanarsa çalıştırmayı durdurun ve **Bölüm 11**'e göre arızayı giderin. Deneme çalıştırması başarıyla tamamlandığında makine üretime alınabilir; ilk kullanım **Bölüm 7**'ye göre yapılır.

Kurulum kontrol listesini ve deneme çalıştırması sonucunu, tarih, makine seri numarası ve kontrolü yapan kişilerin imzasıyla birlikte saklayın.
