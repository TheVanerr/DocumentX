# 5.6 Haberleşme bağlantıları

LYM serisi makineler, röle tabanlı bağımsız bir kumanda sistemiyle çalışır. Makinede PLC, operatör paneli veya haberleşme arayüzü bulunmaz.

| Parametre | Durum |
| :--- | :--- |
| **Endüstriyel haberleşme protokolü (Profinet, Modbus vb.)** | Yok |
| **Üst sistem (MES / SCADA) bağlantısı** | Yok |
| **Uzaktan erişim** | Yok |

Makine, tesis otomasyon sistemine bağlanmadan çalışır. Kurulum sırasında herhangi bir haberleşme bağlantısı yapılmasına gerek yoktur.
