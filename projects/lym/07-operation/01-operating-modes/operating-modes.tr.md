# 7.1 Çalışma modu

LYM serisi makineler tek çalışma moduna sahiptir: **zamanlayıcı kontrollü yıkama çevrimi**. Operatör START butonuna bastığında, zamanlayıcıda ayarlanan süre boyunca sepet döner ve yıkama pompası çalışır; süre dolduğunda makine kendiliğinden durur.

| Mod | Durum |
| :--- | :--- |
| **Otomatik yıkama çevrimi** | Mevcut; tek çalışma modu |
| **Manuel mod** | Yok |
| **Bakım / ayar modu** | Yok |
| **Adım adım (step) mod** | Yok |

Yıkama çevrimi dışında yalnızca iki fonksiyon kullanılabilir:

- **TEST butonu:** Sepeti, yükleme ve boşaltma sırasında konumlandırmak için buton basılı tutulduğu sürece döndürür (**Bkz. Bölüm 3.4.5**).
- **Isıtıcı şalteri:** Yıkama çevriminden bağımsız olarak tank suyunu ısıtır (**Bkz. Bölüm 3.4.7**).

Mod seçici bulunmadığından, modlar arasında geçiş yapılmaz. Bakım ve temizlik çalışmaları makine enerjisiz durumdayken, LOTO uygulanarak yapılır (**Bkz. Bölüm 2.4**).
