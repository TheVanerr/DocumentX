# 13.1 Teslim edilen dokümanlar

Makineyle birlikte aşağıdaki dokümanlar teslim edilir. Teslim alma sırasında dokümanların eksiksiz olduğunu kontrol edin (**Bkz. Bölüm 4.1.2**).

| Doküman | Teslim şekli | Dosya adı / revizyon |
| :--- | :--- | :--- |
| **Kullanım kılavuzu** | Bu doküman | – |
| **Elektrik şeması** | Ayrı doküman | [EKSİK] |
| **Yerleşim (layout) çizimi** | Ayrı doküman | [EKSİK] |
| **Parça listesi (BOM)** | Kılavuza gömülü | **Bölüm 13.3** |
| **AB Uygunluk Beyanı** | Ayrı doküman | [EKSİK] |
| **Garanti belgesi** | Ayrı doküman | – |

Aşağıdaki dokümanlar LYM serisi için uygulanmaz:

| Doküman | Durum |
| :--- | :--- |
| Pnömatik şema | Uygulanmaz (pnömatik devre yok) |
| Hidrolik şema | Uygulanmaz (hidrolik devre yok) |
| PLC programı ve HMI proje yedeği | Uygulanmaz (PLC ve HMI yok) |
| I/O listesi | Uygulanmaz |

Garanti kapsamı, süresi ve koşulları yalnızca makineyle birlikte teslim edilen garanti belgesinde tanımlanır. Bu kılavuz garanti koşullarını tanımlamaz.

Termostat (GEMO DT481) ve zamanlayıcı (GEMO DZ482) gibi satın alınan bileşenlerin üretici kullanım talimatları: [EKSİK]
