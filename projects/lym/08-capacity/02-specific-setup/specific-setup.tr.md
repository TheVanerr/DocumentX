# 8.2 Parçaya özel proses ayarları

LYM serisi makinelerde reçete kayıt sistemi bulunmaz. Her parça tipi için belirlenen proses ayarları (sıcaklık, süre, kimyasal konsantrasyonu), her çevrim öncesinde termostat ve zamanlayıcı üzerinden elle ayarlanır.

Üretici, parça tipine özel standart reçete sunmaz. Parça tipi bazında ayarların belirlenmesi **Bölüm 6.7**'de açıklanmıştır. Belirlenen ayarları aşağıdaki örnek kayıt tablosuna benzer bir formda tutun ve formu makinenin yanında operatörlerin erişebileceği bir yerde bulundurun.

| Parça tipi / kodu | Sıcaklık (°C) | Yıkama süresi (dk) | Kimyasal ve konsantrasyon | Çevrim başına adet | Not |
| :--- | :---: | :---: | :--- | :---: | :--- |
| | | | | | |
| | | | | | |
| | | | | | |

Ayar kayıt formu, işletmenin doküman sisteminde saklanmalı ve her yeni parça tipi eklendiğinde güncellenmelidir (**Bkz. Bölüm 14.1**).
