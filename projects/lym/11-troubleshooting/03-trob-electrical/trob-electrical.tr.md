# 11.3 Elektrik arızaları

Bu alt bölüm, makinenin elektrik koruma elemanlarının davranışını özetler. Elektrik arızalarının teşhisi ve giderilmesi yalnızca yetkili elektrik personeli tarafından yapılır. Elektrik şeması, makineyle birlikte teslim edilen doküman paketinde yer alır (**Bkz. Bölüm 13.2**).

| Konu | Açıklama |
| :--- | :--- |
| **Motor koruması** | Yıkama pompası ve sepet redüktörü, termik aşırı yük röleleri ile korunur. Termik röle, aşırı akım veya aşırı ısınmada devreyi keser. Pompa ve redüktör termik atmaları pano üzerindeki arıza lambası ile bildirilir (**Bkz. Bölüm 11.2**, Arıza 1–2). |
| **Termik röle değerleri** | LYM 950: sepet redüktörü LR2K0310 (2,60–3,7 A), yıkama pompası LR2K0312 (3,70–5,5 A). LYM 1150 / 1350 / 1500 termik ayarları: [EKSİK] |
| **Opsiyon motorları** | Kurutma fanı, yağ sıyırıcı, buhar tahliye fanı ve drenaj pompası ayrı termik rölelerle korunur; arıza lambası yoktur (**Bkz. Bölüm 11.2**, Arıza 4). |
| **Kaçak akım** | Kaçak akım koruma cihazı, herhangi bir devrede yalıtım hatası oluştuğunda tüm beslemeyi keser (**Bkz. Bölüm 11.2**, Arıza 5). |
| **Faz sırası** | Faz sırası yanlışsa faz sıra rölesi makinenin çalışmasına izin vermez (**Bkz. Bölüm 5.5.2**). |
| **Faz kaybı** | Faz kaybındaki makine davranışı: [EKSİK]. Elektrik şemasına bakın (**Bkz. Bölüm 13.2**). |
| **Frekans inverteri** | Yoktur; tüm motorlar şebekeye doğrudan bağlıdır (DOL). |
| **Kablo renk kodları** | Elektrik şemasına bakın (**Bkz. Bölüm 13.2**). |

Termik röleyi, aşırı akımın nedeni giderilmeden resetleyerek makineyi tekrar çalıştırmayın. Termik röle ayar değerlerini artırmayın; daha yüksek ayar değeri motoru korumasız bırakır.
