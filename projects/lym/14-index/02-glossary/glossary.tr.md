# 14.2 Kısaltmalar ve terimler sözlüğü

## 14.2.1 Kısaltmalar

| Kısaltma | Açılımı | Açıklama |
| :--- | :--- | :--- |
| **BOM** | Bill of Materials | Parça listesi; makinenin montaj ve yedek parça kalemleri (**Bkz. Bölüm 13.3**) |
| **CIP** | Cleaning In Place | Yerinde temizlik sistemi; LYM serisinde bulunmaz |
| **COP** | Clean Out of Place | Sökülerek temizlik sistemi; LYM serisinde bulunmaz |
| **DOL** | Direct On Line | Motorun frekans inverteri olmadan şebekeye doğrudan bağlanması |
| **In** | Nominal akım | Şalter, sigorta veya termik rölenin nominal akım değeri (A) |
| **IP** | Ingress Protection | Elektrik muhafazasının toz ve suya karşı koruma derecesi |
| **KKD** | Kişisel koruyucu donanım | Operatör ve bakım personelinin kullandığı koruyucu ekipman (**Bkz. Bölüm 2.6**) |
| **LOTO** | Lock Out / Tag Out | Bakım, temizlik ve onarım öncesinde enerjinin izole edilmesi, kilitlenmesi ve etiketlenmesi (**Bkz. Bölüm 2.4**) |
| **P&ID** | Piping and Instrumentation Diagram | Boru ve enstrümantasyon diyagramı |
| **PE** | Protective Earth | Koruma topraklaması iletkeni |
| **PV** | Process Value | Termostat ekranında ölçülen anlık değer (su sıcaklığı) |
| **RCD** | Residual Current Device | Kaçak akım koruma cihazı |
| **SV** | Set Value | Termostat ekranındaki hedef ayar değeri (hedef sıcaklık) |

## 14.2.2 Makine ve proses terimleri

| Terim | Açıklama |
| :--- | :--- |
| **Döner yıkama sepeti** | Parçaların yıkama sırasında kendi ekseni etrafında döndürüldüğü galvaniz veya paslanmaz çelik yük taşıyıcı |
| **Emiş filtresi** | Tank içinde pompa emiş borusu üzerindeki filtre; pompayı partiküllerden korur |
| **Hassas filtre** | Pompa çıkış hattında ince partikülleri tutan torba filtre düzeneği (opsiyon) |
| **İmalat sonu dokümanı (as-built)** | Makinenin fiili teslim konfigürasyonunu yansıtan teknik doküman |
| **Interlock kilit** | Kapağı yıkama çevrimi süresince kilitleyen emniyet kilidi (opsiyon) |
| **Jog / TEST** | Sepetin, yıkama çevrimi dışında buton basılı tutulduğu sürece döndürülmesi |
| **Kapak kapalı switchi** | Kapağın açık veya kapalı olduğunu emniyet devresine bildiren limit switch |
| **Kurutma ünitesi** | Yıkama sonrasında parçaları hava akışıyla kurutan fan veya blower sistemi (opsiyon) |
| **Ön filtre** | Yıkama hücresinden tanka dönen sudaki kaba kirleri ve talaşları tutan filtre |
| **Opsiyonel donanım** | Standart konfigürasyona sipariş üzerine eklenen ekipman |
| **Pako şalter** | Döner kumanda kollu açma-kapama şalteri; ana şalter ve ısıtıcı şalterinde kullanılır |
| **Proses suyu** | Yıkama tankında ısıtılan, su ve alkali yıkama kimyasalından oluşan temizleme sıvısı |
| **Püskürtme kolu / nozul** | Basınçlı proses suyunu parça yüzeyine yönlendiren dağıtım elemanları |
| **Seviye bekçisi** | Tank su seviyesini izleyen şamandıralı switch; düşük seviyede ısıtıcıyı ve pompayı devre dışı bırakır |
| **Taşıma arabası** | Sepetin makine dışında yüklenmesini ve makineye sürülmesini sağlayan tekerlekli aparat |
| **Termik röle** | Motor aşırı akımında devreyi kesen koruma elemanı; reset gerektirir |
| **Termokupl** | Tank su sıcaklığını termostata ileten sıcaklık sensörü |
| **Termostat** | Su sıcaklığını ölçen ve ısıtıcıyı kumanda eden dijital cihaz (GEMO DT481) |
| **Torba filtre** | Hassas filtrede kullanılan, değiştirilebilir 200 mikron filtre torbası |
| **Yağ sıyırıcı** | Tank yüzeyindeki yüzer yağı mekanik olarak uzaklaştıran yardımcı ekipman (opsiyon) |
| **Yıkama hücresi** | Sepetin, püskürtme kollarının ve nozulların bulunduğu, kapakla kapatılan paslanmaz çelik kabin |
| **Zamanlayıcı** | Yıkama çevrimi süresini geri sayarak kontrol eden dijital zaman rölesi (GEMO DZ482) |

## 14.2.3 Doküman terimleri

| Terim | Açıklama |
| :--- | :--- |
| **Alternatif parça** | Konfigürasyona göre birbirinin yerine kullanılan parça seçeneklerinden biri |
| **Montaj adedi** | Parça listesinde, makinede monte edilmiş parça sayısı; önerilen yedek stok miktarı değildir |
| **Teslim paketi** | Makineyle birlikte verilen teknik doküman seti (**Bkz. Bölüm 13**) |
