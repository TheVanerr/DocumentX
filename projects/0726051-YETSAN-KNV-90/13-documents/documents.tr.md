# 13. DOKÜMANLAR

Bu bölüm, **KNV 90 7500 2B** (seri **0726051**) makinesine ait teslim edilen harici dokümanları, kılavuza gömülü teknik referansları ve yedek parça listesini (BOM) tanımlar.

Bu makinede PLC/HMI bulunmadığından PLC programı, HMI projesi ve I/O listesi gibi dokümanlar **uygulanmaz**. Teslim paketindeki elektrik şeması, pano içi koruma elemanlarının (MKŞ, RCCB, sigorta, kontaktör) hangi motoru/ısıtıcıyı beslediğini ve BLOWER 1/2 anahtarlarının hangi blower motorlarını sürdüğünü gösteren birincil referanstır. Yedek parça listesi ayrı PDF değildir; **Bölüm 13.3.1** tablosu ve proje kökündeki **0726051-YETSAN-KNV 90 PARCA LISTESI** dosyası kullanılır.

| Teslim tipi | İçerik |
| :--- | :--- |
| **Ayrı evrak** | Elektrik şeması, makine layout çizimi — dosya adı/rev [EKSİK] |
| **Kılavuza gömülü** | BOM (**13.3**), arıza tablosu (**11.1.2**), MKŞ tespit tablosu (**11.1.3**), bakım takvimi (**9.1.3**) |
| **Üçüncü taraf kılavuz** | Delta VFD-EL inverter kılavuzu, GEMO DTH2 termostat kılavuzu, Omron G9SB / F3S switch dokümanı |

| Alt bölüm | Konu |
| :--- | :--- |
| **13.1** | Teslim edilen doküman listesi |
| **13.2** | Çizimler ve layout referansı |
| **13.3** | Parça listesi (BOM) — 40 kalem |
