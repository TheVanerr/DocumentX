# 6.7 Sonstige Einstellungen

An dieser Maschine gibt es **keine** weiteren Einstellpunkte außerhalb des Umfangs von **6.1–6.6**. Alle vom Bediener vornehmbaren Einstellungen sind in den folgenden Kapiteln zusammengefasst:

| Thema | Kapitel |
| :--- | :--- |
| Thermostat-Sollwerte (TANK 1/2, DRYING 1/2) | 6.3.3 |
| Fördergeschwindigkeit (20–60 Hz) | 6.3.4 |
| Pneumatik-Druckregler (6 bar) | 6.5.1 |
| Funktionen ein-/ausschalten (Heizung, Pumpe, Blower, Trocknung, Ölskimmer, Ölabscheider, Förderer) | 7.1 — Bedienfeld |
| Prozessaufzeichnung (produktbezogene Geschwindigkeit und Temperatur) | 8.2 |

---

## 6.7.1 Status der sonstigen Einstellungen

| Parameter | Wert / Beschreibung |
| :--- | :--- |
| Sonstige Einstellpunkte | Keine Einstellung erforderlich |
| Datum / Uhrzeit / Sprache | Nicht zutreffend — kein HMI |

Entsteht ein neuer Einstellbedarf (Signal an ein übergeordnetes System, Zusatzfunktion, automatische Befüllung), wenden Sie sich an den **autorisierten Herstellerservice** (**Siehe Kapitel 1.3**); diese Änderungen erfordern eine Revision des Schaltschranks und des Schaltplans.
