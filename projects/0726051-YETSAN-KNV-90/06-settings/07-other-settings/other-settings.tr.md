# 6.7 Diğer ayarlar

Bu makinede **6.1–6.6** kapsamı dışında tanımlanacak ek ayar noktası **bulunmamaktadır**. Operatör tarafından yapılabilecek tüm ayarlar şu bölümlerde toplanmıştır:

| Konu | Bölüm |
| :--- | :--- |
| Termostat set değerleri (TANK 1/2, DRYING 1/2) | 6.3.3 |
| Konveyör hızı (20–60 Hz) | 6.3.4 |
| Pnömatik regülatör (6 bar) | 6.5.1 |
| Fonksiyon aç/kapa (ısıtıcı, pompa, blower, kurutma, yağ sıyırıcı, yağ ayırıcı, konveyör) | 7.1 — operatör paneli |
| Proses kaydı (ürün bazlı hız ve sıcaklık) | 8.2 |

---

## 6.7.1 Diğer ayar durumu

| Parametre | Değer / Açıklama |
| :--- | :--- |
| Diğer ayar noktaları | Herhangi bir ayara gerek yoktur |
| Tarih / saat / dil | Uygulanmaz — HMI yok |

Yeni ayar ihtiyacı (üst sistem sinyali, ek fonksiyon, otomatik dolum) doğduğunda **üretici yetkili servisi** ile görüşün (**Bkz. Bölüm 1.3**); bu değişiklikler elektrik panosu ve şema revizyonu gerektirir.

---

Günlük operasyon için bkz. **Bölüm 7**; kapasite için bkz. **Bölüm 8**.
