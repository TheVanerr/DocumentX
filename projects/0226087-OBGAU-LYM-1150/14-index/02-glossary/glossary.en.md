# 14.2 Glossary of abbreviations and terms

## 14.2.1 Abbreviations

| Abbreviation | Full form | Explanation |
| :--- | :--- | :--- |
| **BOM** | Bill of Materials | Parts list; the assembly and spare part items of the machine (**See Chapter 13.3**) |
| **CIP** | Cleaning In Place | In-place cleaning system; not present on this machine |
| **COP** | Clean Out of Place | Cleaning system requiring disassembly; not present on this machine |
| **DOL** | Direct On Line | Direct connection of the motor to the mains without a frequency inverter |
| **In** | Rated current | Rated current value (A) of the switch, fuse or thermal overload relay |
| **IP** | Ingress Protection | Degree of protection of the electrical enclosure against dust and water |
| **PPE** | Personal protective equipment | Protective equipment used by the operator and maintenance personnel (**See Chapter 2.6**) |
| **LOTO** | Lock Out / Tag Out | Isolation, locking and tagging of energy before maintenance, cleaning and repair (**See Chapter 2.4**) |
| **P&ID** | Piping and Instrumentation Diagram | Piping and instrumentation diagram |
| **PE** | Protective Earth | Protective earth conductor |
| **PV** | Process Value | Instantaneous measured value shown on the thermostat display (water temperature) |
| **RCD** | Residual Current Device | Residual current protective device |
| **SV** | Set Value | Target set value shown on the thermostat display (target temperature) |

## 14.2.2 Machine and process terms

| Term | Explanation |
| :--- | :--- |
| **Rotating washing basket** | Galvanised or stainless steel load carrier in which the parts are rotated about their own axis during washing |
| **Suction filter** | Filter on the pump suction pipe inside the tank; protects the pump from particles |
| **Fine filter** | Bag filter arrangement on the pump outlet line that retains fine particles (option) |
| **As-built document** | Technical document reflecting the actual delivered configuration of the machine |
| **Interlock lock** | Safety lock that locks the lid for the duration of the washing cycle (option) |
| **Jog / TEST** | Rotation of the basket outside the washing cycle for as long as the button is held pressed (panel label BASKET ROTATION) |
| **Lid-closed switch** | Limit switch that signals to the safety circuit whether the lid is open or closed |
| **Lid latch** | Manually opened and closed locking latch at the front centre that holds the top lid in the closed position |
| **Gas spring** | Support element containing pressurised gas that holds the top lid in the open position; inspected monthly (**See Chapter 9.1.7**) |
| **Drying unit** | Fan or blower system that dries the parts with an air flow after washing (option) |
| **Pre-filter** | Filter that retains coarse dirt and swarf in the water returning from the washing chamber to the tank |
| **Optional equipment** | Equipment added to the standard configuration on order |
| **Cam switch** | On-off switch with a rotary control knob; used for the main switch and the heater switch |
| **Process water** | Cleaning liquid consisting of water and alkaline washing chemical, heated in the washing tank |
| **Spray arm / nozzle** | Distribution elements that direct the pressurised process water onto the part surfaces |
| **Level switch** | Float switch that monitors the tank water level; disables the heater and the pump at low level |
| **Transport trolley** | Wheeled device that allows the basket to be loaded outside the machine and rolled into the machine (option) |
| **Thermal overload relay** | Protective element that interrupts the circuit on motor overcurrent; requires a reset |
| **Thermocouple** | Temperature sensor that transmits the tank water temperature to the thermostat |
| **Thermostat** | Digital device that measures the water temperature and controls the heater (GEMO DT481) |
| **Bag filter** | Replaceable 200 micron filter bag used in the fine filter |
| **Oil skimmer** | Auxiliary equipment that mechanically removes floating oil from the tank surface (option) |
| **Washing chamber** | Stainless steel cabinet closed by the lid, which houses the basket, the spray arms and the nozzles |
| **Timer** | Digital time relay that controls the washing cycle time by counting down (GEMO DZ482) |

## 14.2.3 Document terms

| Term | Explanation |
| :--- | :--- |
| **Alternative part** | One of the part options used interchangeably depending on the configuration |
| **Fitted quantity** | In the parts list, the number of the part fitted on the machine; not the recommended spare stock quantity |
| **Delivery package** | Set of technical documents supplied with the machine (**See Chapter 13**) |
