# 13.3 Parts list

This section gives the complete parts list (BOM) of the LYM 1150 NS machine (serial no. 0226087). The parts list is the basis for spare part orders and maintenance planning. When ordering spare parts, state the model and serial number of the machine and the order code of the part (**See Chapter 1.3**).

The columns of the table have the following meanings:

| Column | Meaning |
| :--- | :--- |
| **Order code** | Manufacturer's order code of the part |
| **Qty** | Number of the part fitted on the machine. This value is not the recommended spare stock quantity. |
| **Standard** | Part included in the standard configuration of the model |
| **Alternative** | One of the parts used interchangeably depending on the configuration (e.g. galvanised or stainless basket). Verify which alternative is fitted on your machine from the delivery documents or on the machine itself. |
| **Option** | Part present only on machines fitted with the relevant optional equipment (**See Chapter 3.1.4**) |

The options and alternative parts fitted on your machine are stated in the order and delivery documents; verify that the part is fitted on your machine before placing an order. The wear and safety parts most frequently replaced during periodic maintenance are summarised in **Chapter 9.1.6**. The technical data of the washing pump are given in **Chapter 3.3.3**.
