# 12.2 Temporary and permanent decommissioning

## 12.2.1 Temporary decommissioning

If the machine will not be used for a period of time because of maintenance, a fault or the production schedule:

1. Carry out the long-term shutdown steps (**See Chapter 7.3.3**).
2. Lock the main switch in the **0** position and attach an "Out of service" tag to the machine.
3. If the shutdown period is to be extended, keep the machine under the storage conditions given in **Chapter 4.2**.

Before returning the machine to service, carry out the checks in **Chapter 4.2.3** and repeat the safety function tests (**See Chapter 5.4**).

## 12.2.2 Permanent decommissioning

If the machine is to be withdrawn from use permanently:

1. Carry out the dismantling steps (**See Chapter 12.1**).
2. Separate the supply cable and the plug from the machine; prevent the machine from being re-energised.
3. Attach a tag to the machine stating that it has been permanently decommissioned.
4. Until it is scrapped, keep the machine in an enclosed area in such a way that it cannot leak into the environment.

If a permanently decommissioned machine is to be returned to use, it must not be operated until it has been inspected by the manufacturer.
