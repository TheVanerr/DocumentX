# 7.1 Operating mode

The machine has a single operating mode: **timer-controlled washing cycle**. When the operator presses the START button, the basket rotates and the washing pump runs for the time set on the timer; when the time has elapsed, the machine stops automatically.

| Mode | Status |
| :--- | :--- |
| **Automatic washing cycle** | Available; the only operating mode |
| **Manual mode** | None |
| **Maintenance / setting mode** | None |
| **Step-by-step (step) mode** | None |

Apart from the washing cycle, only two functions can be used:

- **TEST button:** Rotates the basket for as long as the button is held pressed, in order to position the basket during loading and unloading (**See Chapter 3.4.5**).
- **Heater switch:** Heats the tank water independently of the washing cycle (**See Chapter 3.4.7**).

As there is no mode selector, there is no switching between modes. Maintenance and cleaning work is carried out with the machine de-energised and LOTO applied (**See Chapter 2.4**).
