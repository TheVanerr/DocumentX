# 7. OPERATION

This chapter defines the daily operation of the machine: the operating mode, starting up the machine, running the washing cycle, loading and unloading the parts and stopping the machine. The instructions in this chapter are intended for operators trained to use the machine.

| **7.5** | Daily operating routine |
| **7.6** | Other operating information |

Before using the machine, familiarise yourself with the functions of the control elements (**See Chapter 3.4**). The installation of the machine and the initial commissioning checks must have been completed in accordance with **Chapter 5**.

The main hazards during operation are hot process water and steam, contact with the washing chemical, the rotating basket and the loading of heavy parts. The operator must use the personal protective equipment specified by the operating company (**See Chapter 2.6**).
