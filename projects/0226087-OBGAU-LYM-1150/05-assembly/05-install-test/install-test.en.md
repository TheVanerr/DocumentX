# 5.5 Installation check and trial run

This section defines the checklist that verifies that the installation has been completed and the trial run of the machine before it is put into production. The machine must not be used for production until all items of the checklist have been marked "Yes".

## 5.5.1 Mechanical installation check

| No | Check | Yes / No |
| :---: | :--- | :---: |
| 1 | The machine has been levelled in accordance with **Chapter 5.2**; the deviation is below 10 mm. | |
| 2 | All four feet are bearing fully on the floor. | |
| 3 | The supply cable has been unwound from the steam vent outlet; the cable and the plug are undamaged. | |
| 4 | The lid latch closes easily; on machines with the interlock lock option, the lock has been set to the **LOCK** position (**See Chapter 5.4.1**). | |
| 5 | The lid seats correctly on the body; the gas springs hold the lid in the open position. | |
| 6 | The pre-filter and the suction filter are in place (**See Chapter 10**). | |
| 7 | The drain valve is closed; there are no leaks at the water and drain connections. | |
| 8 | The lid gas springs hold the lid in the open position (**See Chapter 9.1.7**). | |
| 9 | The transport trolley (option) has been assembled; the trolley fits fully against the machine and the basket can be rolled without snagging (**See Chapter 5.1.2**). | |

## 5.5.2 Electrical commissioning check

The electrical checks are carried out by authorised electrical personnel in the following order. Energising sequence: main switch, residual current device, circuit breakers.

| No | Check | Yes / No |
| :---: | :--- | :---: |
| 1 | The mains connection has been completed; protective earth (PE) continuity has been verified. | |
| 2 | The main switch has been set to the **1** position. | |
| 3 | The residual current device and all circuit breakers inside the panel are switched on (in circuit). | |
| 4 | The phase sequence relay is giving an output (checked by means of the status indicator on the relay). | |
| 5 | The emergency stop is in the released position; the reset lamp lights when the RESET button is pressed. | |

If the phase sequence relay does not give an output, set the main switch to the **0** position, lock out the supply circuit on the plant side and have authorised electrical personnel swap two of the phase conductors at the socket. Do not change the phases inside the machine panel.

## 5.5.3 Trial run

After the testing of the safety functions (**See Chapter 5.4**) has been completed successfully, carry out the trial run:

1. Check that the tank is full (**See Chapter 5.3.2**).
2. Set the heater switch to the **1** position and set the target temperature on the thermostat (**See Chapter 3.4.8**). Observe that the measured temperature (PV) on the thermostat display is rising.
3. With the basket empty, press the TEST button; check that the basket rotates without snagging and without abnormal noise.
4. Close the lid, set the timer and press the START button.
5. Run the machine with the basket empty for **60 minutes**. This period can be set on the timer as a single cycle or as several cycles.
6. During the run, check that there is no abnormal noise or vibration from the pump and the gear motor.
7. Check that there are no leaks at the pipe connections, the pump seal and the drain valve.
8. Check that none of the fault lamps is lit and that the machine does not shift on the floor.
9. Check that the pump and the basket stop automatically at the end of the period.

If a fault lamp lights during the trial run, stop the run and rectify the fault in accordance with **Chapter 11**. When the trial run has been completed successfully, the machine can be put into production; first use is carried out in accordance with **Chapter 7**.

Keep the installation checklist and the trial run result together with the date, the machine serial number and the signatures of the persons who carried out the checks.
