# 5.6 Communication connections

The machine operates with a stand-alone relay-based control system. The machine has no PLC, operator panel or communication interface.

| Parameter | Status |
| :--- | :--- |
| **Industrial communication protocol (Profinet, Modbus, etc.)** | None |
| **Higher-level system (MES / SCADA) connection** | None |
| **Remote access** | None |

The machine operates without connection to the plant automation system. No communication connections need to be made during installation.
