# 6.3 Electrical settings

This section covers the thermostat and timer settings made by the operator and the electrical protection settings checked by authorised electrical personnel.

## 6.3.1 Thermostat setting (GEMO DT481)

The thermostat determines the target temperature (SV) of the process water. The target temperature is determined by the operating company according to the type of contamination on the parts and the recommended operating temperature of the chemical used.

1. Read the measured temperature (PV) and the current target temperature (SV) on the thermostat display.
2. Set the SV value to the required temperature using the setting keys of the thermostat. For details of the key operations, refer to the operating instructions of the thermostat manufacturer.
3. Confirm from the SV value on the display that the setting has been saved.

The target temperature may be no higher than **70 °C** (**See Chapter 3.4.8**). If the operating temperature recommended by the chemical manufacturer is above 70 °C, that chemical is not suitable for use in this machine.

## 6.3.2 Timer setting (GEMO DZ482)

The timer determines the duration of a washing cycle. The time is set within the range 0–100 minutes.

1. While no washing cycle is running, set the washing time in minutes using the setting keys of the timer. For details of the key operations, refer to the operating instructions of the timer manufacturer.
2. Confirm the set time on the display.

Determining the washing time according to the part type is described in **Chapter 8**.
