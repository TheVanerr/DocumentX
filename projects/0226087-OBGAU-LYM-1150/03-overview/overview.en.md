# 3. OVERVIEW

This chapter describes the structure, operating principle, limits of use, technical specifications, control elements and layout requirements of the LYM 1150 NS rotating-basket industrial parts washing machine. The information given in this chapter applies to the machine with serial no **0226087** manufactured for OBG Automotive; optional equipment is described in **Chapter 3.1.4**.

All personnel assigned to the transport, installation, operation and maintenance of the machine must read this chapter before starting the relevant work. Knowing how the machine works and within which limits it may be used is a prerequisite for correctly understanding the instructions given in the following chapters.

| Section | Subject |
| :--- | :--- |
| **3.1** | Machine description, main components, operating principle and optional equipment |
| **3.2** | Intended use, limits of use and reasonably foreseeable misuse |
| **3.3** | Technical specifications and utility connection values |
| **3.4** | Control panel and control elements |
| **3.5** | Machine layout and space requirements |

The technical values given in Chapter 3.3 and the space requirements given in Chapter 3.5 are the single reference source of this manual. These values are not repeated in the installation, adjustment and maintenance chapters; reference is made to the relevant section instead.

General safety rules, residual risks, energy isolation (LOTO) and the emergency stop procedure are defined in **Chapter 2**.
