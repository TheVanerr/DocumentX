# 8.2 Part-specific process settings

The machine has no recipe storage system. The process settings determined for each part type (temperature, time, chemical concentration) are set manually on the thermostat and the timer before each cycle.

The manufacturer does not provide part-specific standard recipes. Determining the settings for each part type is described in **Chapter 6.7**. Keep the settings determined in a form similar to the example record table below, and keep the form next to the machine in a place accessible to the operators.
