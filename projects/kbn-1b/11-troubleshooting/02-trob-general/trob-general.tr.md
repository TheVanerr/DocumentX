# 11.2 Genel arızalar ve yıkama kalitesi sorunları

Tablo: Genel arızalar

| Belirti | Olası neden | Giderme yöntemi | Yapan |
|---|---|---|---|
| Makine çalışmıyor, kumanda panelinde gösterge ve lambalar sönük | Ana şalter kapalı | **Ana şalteri** "I" konumuna getirin. | Operatör |
| | Tesis tarafındaki besleme sigortası kapalı veya atmış | Besleme sigortasını kontrol ettirin. | Elektrik personeli |
| | Kumanda devresi sigortası atmış | Sigortanın atma nedenini bulun ve sigortayı kurun. | Elektrik personeli |
| Çevrim başlamıyor | Acil durdurma butonu basılı | Butonu serbest bırakın (**Bkz. Bölüm 2.3.2**). | Operatör |
| | Kapak tam kapanmamış | Kapağı tam kapatın; kapak kılavuzlarında ve kapağın alt kenarında parça veya talaş olmadığını kontrol edin. | Operatör |
| | Kapak emniyet şalteri kapağı algılamıyor | Şalteri ve konumunu kontrol edin (**Bkz. Bölüm 11.6**). | Bakım personeli |
| | Bir ikaz lambası yanıyor (arıza var) | Arızayı **Bölüm 3.4.3**'e göre belirleyin ve giderin; ardından **RESET** butonuna basın. | Operatör / bakım personeli |
| | Yıkama süresi sıfıra ayarlı | Yıkama süresini ayarlayın (**Bkz. Bölüm 6.6.2**). | Operatör |
| Parçalar temiz çıkmıyor | Yıkama sıvısı sıcaklığı düşük | Sıcaklık ayarını kontrol edin; sıvının ayar sıcaklığına ulaşmasını bekleyin (**Bkz. Bölüm 6.6.1**). | Operatör |
| | Yıkama süresi kısa | Süreyi artırın (**Bkz. Bölüm 6.6.2**). | Operatör |
| | Kimyasal konsantrasyonu düşük veya sıvı aşırı kirlenmiş | Kimyasal ekleyin veya sıvıyı değiştirin (**Bkz. Bölüm 10.1.4**). | Operatör / bakım personeli |
| | Nozullar tıkalı | Nozulları temizleyin (**Bkz. Bölüm 9.1.3**). | Bakım personeli |
| | Parçalar birbirini örtüyor veya püskürtme yönüne kapalı yerleştirilmiş | Parçaları **Bölüm 8.2**'ye göre yeniden yerleştirin. | Operatör |
| | DS modellerde sepet, DN modellerde nozul sistemi dönmüyor | **Bölüm 11.4**'teki ilgili satıra bakın. | Bakım personeli |
| Parçalarda leke veya kimyasal kalıntısı kalıyor | Kimyasal konsantrasyonu yüksek | Kimyasal tedarikçisinin önerdiği konsantrasyona göre sıvıyı seyreltin veya değiştirin. | Bakım personeli |
| | Parçalar çevrimden sonra uzun süre bekletilmiş | Parçaları çevrimden sonra kısa sürede boşaltın ve kurutun. | Operatör |
| Aşırı köpük oluşuyor | Kimyasal yüksek köpüren tipte veya fazla eklenmiş | Düşük köpüklü kimyasal kullanın; konsantrasyonu düşürün (**Bkz. Bölüm 7.6.3**). | Bakım personeli |
| | Sıvı sıcaklığı kimyasalın köpüksüz çalışma sıcaklığının altında | Sıvının, kimyasal tedarikçisinin önerdiği sıcaklığa ulaşmasını bekleyin. | Operatör |
| Çevrim sırasında kapak kenarlarından sıvı veya buhar çıkıyor | Kapak tam kapanmamış | Kapağı tam kapatın; kılavuzları temizleyin (**Bkz. Bölüm 10.1.3**). | Operatör |
| | Kapak eğilmiş veya kılavuzlarında aşınma var | Kapağı ve kılavuzları kontrol ettirin (**Bkz. Bölüm 9.1.7**). | Bakım personeli |
| Kabin çevresine buhar yayılıyor | Buhar tahliye fanı çalışmıyor | **Bölüm 11.3**'teki ilgili satıra bakın. | Elektrik personeli |
| | Buhar tahliye kanalı tıkalı veya bağlantısı ayrılmış | Kanalı ve bağlantısını kontrol edin (**Bkz. Bölüm 9.1.10**). | Bakım personeli |
| Makine çevresinde zeminde sıvı birikiyor | Pompa, boru veya tahliye vanasında sızıntı | Sızıntı noktasını bulun ve bağlantıyı sıkın veya contayı değiştirin. | Bakım personeli |
| | Tank fazla doldurulmuş, sıvı taşıyor | Tankı seviye sınırına kadar boşaltın (**Bkz. Bölüm 7.2.2**). | Operatör |
| Sepet arabaya çekilemiyor veya kabine itilemiyor | Taşıma arabası rayları kabin raylarıyla hizalı değil | Arabayı yeniden hizalayın (**Bkz. Bölüm 7.4.2**). | Operatör |
| | Raylarda talaş veya sıkışmış parça var | Rayları temizleyin (**Bkz. Bölüm 9.1.11**). | Operatör |
| | Sepet makaraları dönmüyor veya hasarlı | Makaraları kontrol ettirin ve değiştirin. | Bakım personeli |
