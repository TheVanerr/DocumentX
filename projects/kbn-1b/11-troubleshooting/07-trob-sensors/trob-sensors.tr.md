# 11.6 Sensör ve kontrol cihazı arızaları

Tablo: Sensör ve kontrol cihazı arızaları

| Belirti | Olası neden | Giderme yöntemi | Yapan |
|---|---|---|---|
| Kapak kapalıyken çevrim başlamıyor | Kapak emniyet şalteri kapağı algılamıyor (şalter kaymış, hedef parça eğilmiş) | Şalterin ve hedef parçanın konumunu kontrol edin; şalteri yerine sabitleyin. Şalteri köprülemeyin. | Bakım personeli |
| | Kapak emniyet şalteri veya kablosu arızalı | Şalteri ve kablosunu kontrol edin; arızalı şalteri değiştirin. | Elektrik personeli |
| Kapak açıkken pompa veya döndürme duruyor ve kapak kapatılınca çevrim devam etmiyor | Kapak emniyet şalteri doğru çalışıyor; çevrim kapak açıldığında kesilmiştir | Kapağı kapatın ve çevrimi yeniden başlatın (**Bkz. Bölüm 7.4**). | Operatör |
| Tank doluyken **SU SEVİYESİ YETERSİZ** yanıyor, makine çalışmıyor | Seviye şalterinin şamandırası kirli veya takılı kalmış | Şamandırayı temizleyin ve serbest hareket ettiğini kontrol edin; ardından **RESET** butonuna basın. | Bakım personeli |
| | Seviye şalteri veya kablosu arızalı | Şalteri ve kablosunu kontrol edin; arızalıysa değiştirin. | Elektrik personeli |
| Dijital kontrol cihazında (E modellerde dijital termostatta) gerçek dışı veya sabit bir sıcaklık görünüyor ya da hata mesajı çıkıyor | Sıcaklık sensörü kablosu kopmuş veya gevşemiş | Sensör kablosunu ve bağlantısını kontrol edin. | Elektrik personeli |
| | Sıcaklık sensörü arızalı | Sensörü ölçün; arızalıysa değiştirin. | Elektrik personeli |
| | Dijital kontrol cihazının parametreleri değişmiş | Cihaz parametrelerini cihazın kendi kılavuzuna göre kontrol edin (**Bkz. Bölüm 13.1**). | Elektrik personeli |
| Göstergedeki sıcaklık ile sıvının gerçek sıcaklığı farklı | Sensör kirli veya kireçlenmiş | Sensörü temizleyin; bir termometreyle karşılaştırarak kontrol edin. | Bakım personeli |
| Yıkama süresi bitmeden çevrim duruyor veya süre bitince durmuyor | Dijital kontrol cihazında (E modellerde dijital zaman rölesinde) süre yanlış ayarlı veya cihaz arızalı | Süre ayarını kontrol edin (**Bkz. Bölüm 6.6.2**); cihaz arızalıysa değiştirin. | Elektrik personeli |
| Tank otomatik dolmuyor, **SU SEVİYESİ YETERSİZ** yanıyor (otomatik dolum opsiyonu) | Su dolum hattının kesme vanası kapalı veya şebeke suyu basıncı düşük | Kesme vanasını açın; şebeke suyu basıncını kontrol edin (**Bkz. Bölüm 5.3.2**). | Operatör |
| | Dolum vanasının girişindeki süzgeç tıkalı | Süzgeci temizleyin (**Bkz. Bölüm 9.1.13**). | Bakım personeli |
| | Dolum vanası, aktüatörü veya üst seviye algılayıcısı arızalı | Dolum vanasını, aktüatörünü ve üst seviye algılayıcısını kontrol edin; arızalı parçayı değiştirin. | Elektrik personeli |
| Tank taşıyor (otomatik dolum opsiyonu) | Dolum vanası kir nedeniyle açık kalmış veya arızalı | Su dolum hattının kesme vanasını kapatın; dolum vanasını temizleyin veya değiştirin. | Bakım personeli |
| | Üst seviye algılayıcısı kirli veya arızalı | Üst seviye algılayıcısını temizleyin; arızalıysa değiştirin. | Bakım personeli |
| Kapak açılmıyor ve kapanmıyor (P DN modeller) | Sepet kabine sonuna kadar itilmemiş veya sepet pimi yuvasına oturmamış | Sepeti kabine sonuna kadar itin ve pimin yuvasına oturduğunu kontrol edin (**Bkz. Bölüm 7.4.2**). Kapağı zorlamayın. | Operatör |
| | Sepet yerinde sensörünün önü kirli veya sensör yerinden oynamış | Makineyi kilitleyin; sensörün önünü temizleyin ve sabitleme somununu kontrol edin (**Bkz. Bölüm 9.1.11**). Sensörü köprülemeyin. | Bakım personeli |
| | Sepet yerinde sensörü veya kablosu arızalı | Sensörü ve kablosunu kontrol edin; arızalı sensörü orijinal parçayla değiştirin. | Elektrik personeli |
| Kapak kapanmıyor (ışık perdesi opsiyonu) | Işık perdesinin önünde kişi, parça veya cisim var | Cismi uzaklaştırın ve ışık perdesini yeniden başlatın (**Bkz. Bölüm 7.6.5**). | Operatör |
| | Işık perdesinin ön camları kirli | Camları temizleyin (**Bkz. Bölüm 9.1.13**). | Operatör |
| | Verici ile alıcının hizası bozulmuş veya ışık perdesi arızalı | Işık perdesinin gösterge lambalarını kendi kılavuzuna göre değerlendirin; hizayı ayarlayın veya arızalı parçayı değiştirin. Işık perdesini köprülemeyin. | Elektrik personeli |
| Kapak kapanmıyor (el koruma sensörü, P modeller) | Sensörün önünde el, parça veya cisim var | Cismi uzaklaştırın ve kapağı yeniden kapatın. | Operatör |
| | Sensörün ön yüzü kirli | Ön yüzü yumuşak bir bezle temizleyin (**Bkz. Bölüm 9.1.13**). | Operatör |
| | Sensörün hizası bozulmuş veya sensör arızalı | Sensörü kontrol edin; hizayı ayarlayın veya arızalı sensörü orijinal parçayla değiştirin. Sensörü köprülemeyin. | Elektrik personeli |
| Isıtma veya yağ sıyırıcı programlanan saatte başlamıyor (zamanlayıcı opsiyonları) | Ana şalter "0" konumunda bırakılmış | Ana şalteri "I" konumunda bırakın (**Bkz. Bölüm 7.3.1**). | Operatör |
| | Zamanlayıcının saati, günü veya programı yanlış | Saati ve programı kontrol edin (**Bkz. Bölüm 6.6.4**). | Bakım personeli |
| | Tanktaki sıvı seviyesi düşük; seviye şalteri kumanda devresini kesmiş | Tankı doldurun ve **RESET** butonuna basın (**Bkz. Bölüm 7.2.2**). | Operatör |
