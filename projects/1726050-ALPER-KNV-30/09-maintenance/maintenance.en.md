# 9. MAINTENANCE

This section defines the preventive maintenance programme, lubrication points and recommended on-site spare parts stock for the **KNV 30 3000 2B** machine. The machine runs on a **24/7 robot** line; there is no continuous operator. Planned maintenance and fault intervention are performed by **maintenance personnel**.

**The periodic maintenance schedule is given in this section.** Filter cleaning steps are defined in **Section 10**; the LOTO procedure is defined in **Section 2.4** — steps are not repeated here. The full parts list (BOM) is given in **Section 13.3.1**; this section contains operational summary tables.

| Parameter | Value |
|-----------|-------|
| Maintenance philosophy | Preventive maintenance |
| Lubrication table | Conveyor 4 points + WITTENSTEIN gearbox (Section 9.1.4) |
| Lubrication points | 4 (conveyor infeed 2 + outfeed 2) |
| Maintenance mode | None — energy isolation with LOTO |

|-------|--------|
| **9.1** | Maintenance instructions — interval, lubrication, spare parts, record form |
