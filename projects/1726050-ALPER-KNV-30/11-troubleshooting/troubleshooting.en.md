# 11. TROUBLESHOOTING

This section defines the diagnosis and remedy methods for faults that may occur on the **KNV 30 3000 2B** machine. The machine runs on a **24/7 robot line**; there is no continuous operator. Fault intervention is performed by **maintenance personnel** or authorised **electrical personnel**.

Alarm information is read from the HMI **Alarm Page** and the stack light. For electrical panel, motor and heater intervention the **LOTO procedure** must be applied (**See Section 2.4**). Emergency stop reset is performed according to **Section 2.5**.

| Parameter | Value |
|-----------|-------|
| Alarm indication | HMI Alarm Page + stack light red |
| Hydraulic / vacuum | Not applicable |

| Subsection | Topic |
|-------|--------|
| **11.1** | Fault finding — diagnosis flow, alarm table |
| **11.2** | General — HMI alarm behaviour, service criteria |
| **11.3** | Electrical — phase, motor, heater |
| **11.4** | Hydraulic — not applicable |
| **11.5** | Pneumatic — air/water pressure, valves |
| **11.6** | Vacuum — not applicable |
| **11.7** | Sensors — RFID, level, leakage, product detection |
