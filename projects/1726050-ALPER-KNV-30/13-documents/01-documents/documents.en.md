# 13.1 List of delivered documents

Technical documents delivered with the machine fall into two groups: **separate documents** (PDF files) and **references embedded in the manual**. File name and revision must be read from the cover sheet or file label in the delivery package.

Machine identity-plate data (**serial no. 1726050**, model **KNV-30**) are mandatory on orders and service requests — see **Section 1.3.2**.

---

## 13.1.1 Customer drawing package (separate documents)

The customer drawing package consists of **three PDFs**:

| # | Document | File name / rev | Use |
|---|---------|-----------------|----------------|
| 1 | **P&ID schematic** | Separate document — delivery package (PDF) | Process and media lines; tank, pump, valve connections |
| 2 | **Electrical schematic** | Separate document — delivery package (PDF) | Panel, motor, sensor, safety circuit — see **3.4**, **5.3**, **11.3** |
| 3 | **Machine layout drawing** | `1726050-ALPER-KNV 30 LAYOUT.pdf` | Layout, infeed/outfeed direction — see **3.5**, **13.2** |

**WARNING — Electricity:** Isolate machine energy and apply **LOTO** before working on the electrical schematic (**Section 2.4**).

The full file name/revision of the P&ID and electrical schematic is stated on the package at delivery; a fixed file name is not defined in this manual.
