# 13.3 Parts list

The machine **spare-parts list (BOM)** is embedded in this manual; it is **not delivered** as a separate document. The full list is given in the **13.3.1** table — other sections contain only a summary or a cross-reference.

---

## 13.3.1 Spare-parts table (22 items)

### Category definitions

| Category | Meaning | Stock recommendation |
|----------|-------|--------------|
| **Critical** | Process or safety stops on failure; immediate replacement required | 0 = on order; ≥1 = keep on site |
| **Recommended** | Performance drops on failure; planned stock is recommended | 0–1 piece on site |
| **Consumable** | Consumed during periodic maintenance/cleaning | According to interval and consumption rate |

### Order procedure

1. Take the **order code** and **part name** from the **13.3.1** table.
2. State model (**KNV-30**), serial no. (**1726050**) and quantity on the order — see **1.3.4**.
3. Use original parts; equivalent parts create warranty and safety risk.
