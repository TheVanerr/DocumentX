# 13. DOCUMENTS

This section defines the external documents delivered with the **KNV 30 3000 2B** (serial **1726050**) machine, the technical references embedded in the manual, and the spare-parts list (BOM).

The delivery package contains **three PDFs**: **P&ID**, **electrical schematic** and **machine layout**. The spare-parts list is not a separate PDF; the **Section 13.3.1** table is used.

| Delivery type | Content |
|-------------|--------|
| **Separate documents (3 PDFs)** | P&ID + Electrical schematic + Layout |
| **Embedded in the manual** | BOM (**13.3**), alarm table (**11.1.2**) |

| Subsection | Topic |
|-------|--------|
| **13.1** | List of delivered documents |
| **13.2** | Drawings and layout reference |
| **13.3** | Parts list (BOM) |
