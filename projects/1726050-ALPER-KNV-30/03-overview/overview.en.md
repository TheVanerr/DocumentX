# 3. GENERAL OVERVIEW

**KNV 30 3000 2B** (model code **KNV-30**, serial no. **1726050**, customer **ALPER ÖZLEM IDEA**) is a conveyor-type, **two-bath** (wash + rinse) parts washing machine designed to remove oil and process dirt accumulated on industrial part surfaces. This chapter is arranged so that operator, maintenance and installation personnel can recognise the machine as a whole and grasp process limits and the technical framework; detailed technical values are given in the related subsections; the same numbers are not repeated in other chapters.

The machine enables parts to pass in sequence through **wash → rinse → drying** processes while travelling on the **conveyor line**. Feed is **left**, discharge is **right**, operator side is **right**. Within this project, part infeed and outfeed are performed by **robot**; the machine is integrated into the line to run **24/7 automatic**. Nominal cycle time is defined as **900 seconds** (15 minutes).

The main modules of the machine are: conveyor, wash pump, rinse pump, oil skimmer, drying fans, exhaust fan, electrical cabinet, HMI, PLC, main switch and protection elements. Module functions and their relationship to each other are explained in **Chapter 3.1**; intended-use limits in **Chapter 3.2**; dimensions, capacity, electrical and motor data in **Chapter 3.3**; control and HMI structure in **Chapter 3.4**; layout and space requirements in **Chapter 3.5**.
