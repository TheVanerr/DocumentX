# 14.2 Glossar

Dieses Glossar definiert die im Handbuch verwendeten Abkürzungen und maschinenspezifischen Begriffe. Sicherheits- und Verfahrensdetails stehen in den jeweiligen Hauptabschnitten.

---

## 14.2.1 Abkürzungen

| Abkürzung | Beschreibung |
|----------|----------|
| **BOM** | Bill of Materials — Ersatzteil- / Materialliste (**13.3.1**) |
| **Cat. 3** | Sicherheitskategorie nach EN ISO 13849-1 (siehe **2.1.3**) |
| **CIP** | Cleaning in Place — an dieser Maschine **nicht vorhanden** |
| **COP** | Cleaning out of Place — automatisches System **nicht vorhanden** |
| **HMI** | Human Machine Interface — Siemens SIMATIC KTP700 Basic PN Bedienpanel |
| **ICC** | Kurzschlussstrom — Anforderung der Speiseleitung **10 kA** (**3.3.3**) |
| **LOTO** | Lockout/Tagout — Energieisolierung und Verriegelung-Kennzeichnung (**2.4**) |
| **PE** | Protective Earth — Schutzleiter (3P+N+**PE**) |
| **PLC** | Programmable Logic Controller — Siemens SIMATIC S7-1200 |
| **P&ID** | Piping and Instrumentation Diagram — Prozess-/Instrumentierungsschema |
| **RFID** | Radio Frequency Identification — Sicherheitssensor der Wartungsklappe (Omron F3STGRNLPU21M1J8; Bestellname MANYETİK KAPI) |
| **RPM** | Umdrehungen je Minute |
| **SWL** | Safe Working Load — sichere Hubkapazität des Gabelstaplers |
| **WEEE** | Waste Electrical and Electronic Equipment — Elektroschrottrecht |

---

## 14.2.2 Begriffe

| Begriff | Beschreibung |
|-------|----------|
| **Not-Aus** | Physische Sicherheitstaste; **4 Stück** an der Maschine; öffnet den Sicherheitskreis (**2.5**, Error-229) |
| **Umlaufventil** | Pneumatikventil für Prozesswassertransfer zwischen Tanks (Error-304/305) |
| **Hauptschalter** | Elektrischer Trennpunkt am Schrankeingang; LOTO-Anwendungspunkt (**2.4**) |
| **Beschickungsrichtung** | Teileeinlauf — an dieser Maschine **linke** Seite |
| **Entnahmerichtung** | Teileauslauf — an dieser Maschine **rechte** Seite |
| **Zykluszeit** | Zeit, in der ein Teil den Tunnel Waschen→Spülen→Trocknen durchläuft; nominell **900 s**. Roboterzyklus und Durchsatz **730 Stk./h** sind getrennte Begriffe (**3.3.2**, **7.4.2**) |
| **Vorbereitung Start** | HMI-Taste; startet automatische Tankfüllung und Aufheizung auf Rezepttemperatur (**7.2.2**) |
| **Dauerhafte Außerbetriebnahme** | Außerbetriebnahme, wenn die Maschine nicht wieder in Betrieb genommen wird (**12.2.1**) |
| **KNV 30 3000 2B** | Kaufmännische Bezeichnung / Modellvariante der Maschine |
| **Förderer** | Servogetriebene Teiletransportstrecke; in die Roboterlinie integriert (**7.4**) |
| **Maschinenstopp** | HMI-Befehl für normalen Stopp (**7.3.1**) |
| **Maschinenstart** | HMI-Befehl zum Start des Automatikzyklus (**7.2.4**) |
| **Automatisches Füllventil** | Pneumatikventil, das Anlagenwasser in die Tanks füllt (Error-300–303) |
| **Bedienerseite** | HMI- und Wartungszugang — an dieser Maschine **rechte** Seite (**3.5**) |
| **Vorfilter** | Einlassfilter des Waschtanks; **tägliche** Reinigung (**10.1.3**) |
| **Pumpen-Eingangsventil** | Handventil in der Pumpen-Saugleitung; muss vor dem Start **offen** sein (**7.2.5**) |
| **Prozessfunktion** | Waschen, Spülen, Trocknen 1/2, Abluft — am HMI wählbar (**7.1.6**) |
| **Rezept** | Am HMI definierter Prozessparametersatz — Temperatur, Funktionswahl (**6.3**, **8**) |
| **Reset** | Wiedereinsetzen des Sicherheitskreises nach Not-Aus oder Alarm (**2.5**, **7.3.2**) |
| **Leckagewanne** | Erfassungsbereich für Wasserleckage unter dem Tank (Error-452) |
| **Signalleuchte** | **Gelb** bereit, **grün** läuft, **rot** Alarm (**3.4.10**) |
| **Beutelfilter** | 200-Mikron-Filter am Pumpenausgang; **wöchentliche** Reinigung/Wechsel (**10.1.4**) |
| **Produkt entnommen Bestätigung** | HMI-Taste; Bestätigung, wenn am Auslaufförderer ein Teil erkannt wird (Error-461) |
| **Ölabstreifer** | Einheit zum Abnehmen von Oberflächenöl im Waschtank (Error-130) |
| **24/7-Betrieb** | Ununterbrochener Roboterlinien-Betriebsmodus (**7.5**, **8**) |
