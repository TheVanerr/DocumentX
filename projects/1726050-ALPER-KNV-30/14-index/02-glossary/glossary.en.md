# 14.2 Glossary

This glossary defines abbreviations used throughout the manual and machine-specific terms. Safety and procedure details are given in the relevant main sections.

---

## 14.2.1 Abbreviations

| Abbreviation | Description |
|----------|----------|
| **BOM** | Bill of Materials — spare-parts / material list (**13.3.1**) |
| **Cat. 3** | EN ISO 13849-1 safety category (see **2.1.3**) |
| **CIP** | Cleaning in Place — **not present** on this machine |
| **COP** | Cleaning out of Place — automatic system **not present** |
| **HMI** | Human Machine Interface — Siemens SIMATIC KTP700 Basic PN operator panel |
| **ICC** | Short-circuit current — supply-line requirement **10 kA** (**3.3.3**) |
| **LOTO** | Lockout/Tagout — energy isolation and lockout-tagout (**2.4**) |
| **PE** | Protective Earth — protective earthing (3P+N+**PE**) |
| **PLC** | Programmable Logic Controller — Siemens SIMATIC S7-1200 |
| **P&ID** | Piping and Instrumentation Diagram — process/instrumentation schematic |
| **RFID** | Radio Frequency Identification — maintenance-cover safety sensor (Omron F3STGRNLPU21M1J8; order name MANYETİK KAPI) |
| **RPM** | Revolutions per minute |
| **SWL** | Safe Working Load — forklift safe lifting capacity |
| **WEEE** | Waste Electrical and Electronic Equipment — e-waste legislation |

## 14.2.2 Terms

| Term | Description |
|-------|----------|
| **Emergency stop** | Physical safety button; **4 units** on the machine; opens the safety circuit (**2.5**, Error-229) |
| **Transfer valve** | Pneumatic valve for process-water transfer between tanks (Error-304/305) |
| **Main switch** | Panel incoming electrical isolation point; LOTO application point (**2.4**) |
| **Infeed direction** | Part inlet — **left** side on this machine |
| **Outfeed direction** | Part outlet — **right** side on this machine |
| **Cycle time** | Time for one part to pass through the wash→rinse→drying tunnel; nominal **900 s**. Robot cycle and **730 pcs/h** throughput are separate concepts (**3.3.2**, **7.4.2**) |
| **Preparation Start** | HMI button; starts automatic tank fill and heating to recipe temperature (**7.2.2**) |
| **Permanent decommissioning** | Taking the machine out of service when it will not be recommissioned (**12.2.1**) |
| **KNV 30 3000 2B** | Machine commercial designation / model variant |
| **Conveyor** | Servo-driven part-transport line; integrated into the robot line (**7.4**) |
| **Machine Stop** | HMI normal stop command (**7.3.1**) |
| **Machine Start** | HMI automatic-cycle start command (**7.2.4**) |
| **Automatic fill valve** | Pneumatic valve that fills the tanks from plant water (Error-300–303) |
| **Operator side** | HMI and maintenance access — **right** side on this machine (**3.5**) |
| **Pre-filter** | Wash-tank inlet filter; **daily** cleaning (**10.1.3**) |
| **Pump inlet valve** | Manual valve on the pump suction line; must be **open** before start (**7.2.5**) |
| **Process function** | Wash, rinse, drying 1/2, exhaust — selected from the HMI (**7.1.6**) |
| **Recipe** | Process-parameter set defined on the HMI — temperature, function selection (**6.3**, **8**) |
| **Reset** | Re-enabling the safety circuit after emergency stop or alarm (**2.5**, **7.3.2**) |
| **Leak tray** | Under-tank water-leak detection zone (Error-452) |
| **Tower light** | **Yellow** ready, **green** running, **red** alarm (**3.4.10**) |
| **Bag filter** | 200-micron filter at pump outlet; **weekly** cleaning/replacement (**10.1.4**) |
| **Product Received Confirm** | HMI button; confirm when a part is detected on the outfeed conveyor (Error-461) |
| **Oil skimmer** | Unit that collects surface oil from the wash tank (Error-130) |
| **24/7 operation** | Continuous robot-line operating mode (**7.5**, **8**) |
