# 6.2 Safety settings

---

## 6.2.1 Safety door / bypass

| Parameter | Value / Description |
|-----------|---------------------|
| Safety door bypass (if any — maintenance only) | Safety door shall under no circumstances be bypassed. For maintenance, open covers after machine power is disconnected. LOTO procedure shall always be applied when power is disconnected |

---

## 6.2.2 Light curtain

| Parameter | Value / Description |
|-----------|---------------------|
| Light curtain adjustment distance (mm) | No light curtain on this machine |

---

## 6.2.3 E-Stop test interval

| Parameter | Value / Description |
|-----------|---------------------|
| E-stop test interval | E-stop test shall be performed once every month |

For detailed test procedure, see Section **5.4.1**.
