# 6.4 Hydraulic settings

The **KNV 30 3000 2B** machine has **no hydraulic system**. Process circulation is provided by electric-motor pumps; position control is by pneumatic (if any) and electric drive. There is **no** hydraulic pressure, flow or valve setting for the operator or maintenance personnel.

This subsection makes clear that hydraulic settings should not be sought; a hydraulic fault-diagnosis table does not apply to this machine (see **Chapter 11** — the related subsection is not applied).

---

## 6.4.1 Hydraulic settings status

| Parameter | Value / Description |
|-----------|------------------|
| Hydraulic system | Not provided |
| Hydraulic settings | No adjustment is required |

Media connections: compressed **air** and **water** (see **Chapters 3.3.5**, **6.5**).
