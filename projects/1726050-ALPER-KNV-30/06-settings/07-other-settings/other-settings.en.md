# 6.7 Other settings

On this machine there are **no** additional OEM adjustment points to define outside the scope of **6.1–6.6**. All parameter changes the operator can make are collected in the following sections:

| Topic | Chapter |
|------|-------|
| HMI temperature, oil skimmer, date/time/language | 6.3 |
| Pneumatic regulator (6 bar) | 6.5 |
| Process function on/off (wash, rinse, drying) | 7.1 — Operating Page |
| Recipe / product parameters | 8.2 |

---

## 6.7.1 Other settings status

| Parameter | Value / Description |
|-----------|------------------|
| Other adjustment points | No adjustment is required |

If a new setting need arises (software update, line integration, MES connection), consult **manufacturer authorised service** (see **Chapter 1.3**). Higher-level system (MES/SCADA) connection is performed **by the customer** (see **Chapter 5.6.2**).

---

For daily operation settings see **Chapter 7**; for capacity/recipe see **Chapter 8**.
