# 6.3. Electrical Settings

---

## 6.3.1. Motor Direction / Phase Check

| Parameter | Value / Description |
|-----------|---------------------|
| Motor direction / phase check | Motor shall run in one direction only. No adjustment is required for this |

Phase direction and sequence were verified during installation with the phase sequence relay (see Section **5.3**).

---

## 6.3.2. Encoder / Feedback

| Parameter | Value / Description |
|-----------|---------------------|
| Encoder / feedback adjustment | Embedded in PLC program. Adjustment shall be performed by our company |

Encoder adjustment shall not be performed by the operator.

## 6.3.3. Analog Scaling

| Parameter | Value / Description |
