# 14.2 Sözlük ve kısaltmalar

## 14.2.1 Terimler

Tablo: Terimler

| Terim | Açıklama |
|---|---|
| Aktif / Pasif | Bir fazın çevrimde yapılıp yapılmayacağını belirleyen seçim. Pasif faz atlanır. |
| Alt sepet | Kabin içinde kalan, kremayer halkalı dönen çerçeve. |
| Ara röle | PLC çıkışını kontaktör, valf veya lamba devresine aktaran küçük röle (R1–R20). |
| Dönen sepet | Alt sepet ile üst sepetten oluşan, parçaları taşıyan ve çevrim boyunca dönen düzenek. |
| Drenaj | Tankın drenaj pompasıyla boşaltılması. |
| Drenaj kolektörü | İki tankın drenaj vanalarını birleştiren ortak boru. |
| Durum penceresi | Çalışma Sayfası'nda makinenin durumunu yazan alan. |
| Emiş filtresi | Pompa emiş ağzındaki delikli filtre. |
| Faz | Çevrimin işlem adımı: yıkama, durulama veya kurutma. |
| Filtre regülatör | Basınçlı havayı süzen ve basıncını ayarlayan eleman. |
| Frekans invertörü | Sepet motorunun hızını ayarlayan elektronik sürücü. |
| Geçiş | Yıkamadan ve durulamadan sonra pompanın durduğu, parçaların süzüldüğü bekleme adımı. |
| GİRİŞ GÖZLEM | Manuel Sayfası'nda giriş sinyallerinin durumunu gösteren bölüm. |
| Güvenlik rölesi | Acil durdurma devresini izleyen ve resetlenene kadar makinenin çalışmasını engelleyen röle. |
| Hazırlık | Tank ısıtmasını açan ve kapatan fonksiyon. |
| Işık perdesi | Kapı açıklığında el ve cisim algılayan optik koruma donanımı. |
| Kaçak akım rölesi | Devrede topraklamaya akım kaçtığında beslemeyi kesen koruma elemanı. |
| Kontaktör | Motor ve ısıtıcıların güç devresini açıp kapatan elektromekanik anahtar. |
| Kremayer | Alt sepetin çevresindeki dişli halka. |
| Kule lambası | Makinenin durumunu renkli ışıkla gösteren lamba. |
| Mekanik salmastra | Pompa milinde sıvı sızdırmazlığını sağlayan eleman. |
| Motor koruma şalteri | Motoru aşırı akıma karşı koruyan şalter (termik). |
| Ön filtre sepeti | Kabinden dönen sıvıdaki talaşı tanka girmeden tutan elekli sepet. |
| Pilotlu çek valf | Hava kesildiğinde silindirdeki havayı hapsederek silindiri bulunduğu konumda tutan valf. |
| Pinyon | Redüktör milindeki, kremayeri döndüren küçük dişli. |
| Reçete | Yıkama, durulama ve kurutma sıcaklık ve sürelerinin kayıtlı olduğu ayar grubu. |
| Reçete Onay | Seçili reçetenin değerlerini makineye gönderen buton. |
| Rezistans soğutma | Kurutmadan sonra ısıtıcı kapalıyken fanın ısıtıcıyı soğutmak için çalıştığı adım. |
| Separatör (ayırıcı) | Tank içinde akışı yönlendiren ve çökeltiyi pompadan uzak tutan sac. |
| Sepet konumlama | Çevrim sonunda sepetin yavaş hızda başlangıç konumuna getirilmesi. |
| Sepet Test | Sepeti çevrim dışında yavaş döndürüp başlangıç konumuna getiren fonksiyon. |
| Seviye sensörü | Tank sıvısının pompa seviyesinin üzerinde olup olmadığını algılayan titreşimli çatal sensör. |
| Tahliye odası | Kabinden dönen sıvıyı tahliye vanalarıyla ilgili tanka yönlendiren oda. |
| Tahliye vanası | Tahliye odasında, dönen sıvıyı yıkama veya durulama tankına yönlendiren pnömatik vana. |
| Taşma hattı | Tankın aşırı dolmasında fazla sıvıyı tahliye eden çıkış. |
| Termokupl | Sıcaklık ölçen sensör (J tipi). |
| Torba filtre | Pompa basma hattında sıvıdaki ince parçacıkları tutan torba elemanlı filtre. |
| Üst sepet (parça ızgarası) | Parçaların yerleştirildiği, yükleme arabasıyla kabine alınan yuvarlak ızgara. |
| Yağ sıyırıcı | Tank sıvısının yüzeyindeki yağı dönen diskle toplayan düzenek. |
| Yataklama tekeri | Sepeti taşıyan POM (delrin) teker. |
| Yükleme arabası | Üst sepeti kabine taşıyan, makineye kilitlenen tekerlekli araba. |

| I/O | Giriş / çıkış |

| ISO | Uluslararası Standartlar Örgütü |
| KKD | Kişisel koruyucu donanım |

| POM | Polioksimetilen (delrin) |
